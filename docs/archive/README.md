# DoseTap documentation archive

Status: Historical and superseded material
Last updated: 2026-09-02

Every descendant of this directory is non-authoritative unless a file explicitly says otherwise. Archived files preserve decisions, evidence, prompts, and prior plans. They may contain obsolete paths, line counts, test totals, service assumptions, or completion claims.

Do not edit an old report to make it describe a later checkout. Add a new dated audit or update a current contract instead.

## Main groups

- `architecture/`: replaced architecture snapshots and hand-written inventories
- `audits/`, `audits_*/`, `audit_sessions_*/`: prior audit evidence
- `automation/`: retired workflow setup
- `contracts/`: replaced contracts
- `design/`: retired design notes
- `governance/`: dated governance implementation reports
- `planning/`: completed or superseded plans and checklists
- `prompts/`: replaced standalone prompts
- `releases/`: dated readiness snapshots
