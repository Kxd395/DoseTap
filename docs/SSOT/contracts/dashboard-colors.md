# Dashboard colors and Night Mode

Dashboard category colors are descriptive, not treatment or health ratings.
Light and Dark retain existing colors. Night Mode uses bright warm foregrounds
that remain visible through the existing global red multiplier. The dashboard
does not add another filter or replace its view identity when appearance changes.
An observed theme supplies one palette through the dashboard environment.

Night legends describe labels, symbols and series rather than claiming blue,
purple or green appearance. Multi-series plots use distinct symbols; stage bars
retain labeled order and values. Missing values remain labeled, never assigned
a severity color or a numeric zero by this presentation change.

The interval scatter labels the built-in 150–240 minute inclusive reference.
It does not establish a historical prescribed window. No metric eligibility,
medication, alarm, provider, theme preference or navigation behavior changes.

Validation must inspect native Dark/Night/Dark screenshots with synthetic
dashboard data, including values, weekday marks, multi-series plots and largest
text. Theme transitions must preserve range, section and navigation state.
